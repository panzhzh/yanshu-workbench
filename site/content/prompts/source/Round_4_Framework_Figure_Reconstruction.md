## 目标

本轮只重构论文的总体方法框架图。它回答“整个方法如何组织并运转”，不重新论证研究意义，也不展开某个局部机制。

成功标准：读者看图后能够沿一条明确路径说清输入、主要阶段或组件、关键信息流和输出，并能带着这一整体心智地图阅读 Method。

## 本轮输入

在同一对话中提供：

1. 第三轮输出的最新完整 `.tex`；
2. 与其一致的最新编译 `.pdf`；
3. 可选：前三轮报告和现有 figures。

先完整阅读 TeX 与 PDF：以 TeX 为术语、公式、符号和结构依据，以 PDF 理解上下文、版面与现有图表。若两者存在会影响绘图的冲突，只提出必要问题，不得猜测。

## 这张图必须完成

- 从 TeX 中确认正式定义的输入、输出、主要组件与接口；每个主要组件只出现一次，并用层级、分组和箭头表达关系。
- 优先呈现决定整体理解的主路径。仅当论文真实依赖分支、共享参数、循环、跨阶段反馈或多模态交互时，才显示这些结构。
- 只有训练与推理差异影响方法理解时才明确区分两者；不得为了画面复杂而增加并行流程。
- 阅读顺序、箭头方向和颜色语义必须全局一致；输入与输出具有清楚边界。

## 不得混入

- 不得重复引言图中的场景—问题叙事，也不得加入实验结果、性能数字、消融结论或研究影响。
- 不得塞入每个子操作、完整公式、损失项推导、超参数、代码级实现或长段说明文字。
- 不得为了视觉对称虚构模块、复制同一组件，或隐藏论文真实存在的关键依赖。
- 只生成这一张总体框架图，不生成引言图、局部技术细节图、备选版本或联系表。

## 统一视觉与文字约束

- 图中所有文字，包括模块名、箭头标签、图例、缩写和变量符号，必须与论文术语、大小写、连字符和符号完全一致；不得翻译、改写或自造近义词，只能使用论文已经定义的缩写。
- 生成前在内部建立精确标签清单并逐字符核对冷门方法名或自造词；不要输出该清单。文字放不下时调整版式，不得擅自缩写。
- 不得发明论文中不存在的模块、数据流、公式、指标、实验结果或因果关系。
- 页面生成本 Prompt 时必须注入用户确认的论文占栏（单栏或跨双栏）与画布比例（`4:3`、`3:4`、`16:9`、`9:16` 或自定义比例）；从一开始按目标栏宽与比例组织内容，不得先生成其他比例再裁切。
- 使用极简论文线稿：纯白画布、细而可印刷的结构线、矩形或轻圆角模块，以对齐、留白和清楚信息流建立层级；禁止渐变、阴影、3D、纹理或装饰性 AI 视觉。
- 使用 Paul Tol “Vibrant”色系，候选强调色依次为 `#0077BB / RGB(0, 119, 187)`、`#EE7733 / RGB(238, 119, 51)`、`#009988 / RGB(0, 153, 136)`、`#CC3311 / RGB(204, 51, 17)`。根据真实信息流和语义分组，在 2–4 种有彩色相中选择最少够用的数量；白底、黑字和深色中性结构线不计入。
- 深色中性细线是边框、箭头与连接线的默认颜色；仅当信息流、实体类别或状态确需区分时才使用候选强调色，相同语义必须同色，不得制造彩虹线条。
- 全图统一使用 Calibri。允许按实际内容加入克制的轻卡通技术插图或语义 icon，但只能表示论文中的真实对象或过程，不得代替核心机制，也不得呈现漫画、吉祥物或营销插画效果。
- 所有模块卡片保持纯白或透明，不设置底色；只通过细边框、对齐、间距和分组标题建立层级。
- 全图严格只使用两级字号：正文/标签与标题；最大字号不得超过最小字号的 `1.25` 倍。最小字号在最终双栏宽度下必须清楚可读，内容放不下时删减标签或重排，不得缩成小字。
- 所有文字使用实黑或近黑色；禁止浅灰色、低透明度或低对比度文字。
- 不使用图内大标题；只保留必要的 panel 标题或步骤标签。不得把论文标题、作者或 caption 放进图片。
- 文字短而清晰，不写段落；保持一条清楚阅读路径，避免垂直文字、交叉箭头和无意义留白。

## 直接生成
